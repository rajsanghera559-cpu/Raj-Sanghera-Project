# 1. Discretization

### Frequency

★★★★★

### Definition

Convert continuous equations into finite computations.

Continuous:

[
\frac{du}{dt}
]

Discrete:

[
\frac{u^{n+1}-u^n}{\Delta t}
]

Meaning:

Reality:

```text id="mx65n2"
continuous
```

Computer:

```text id="b3n9zv"
samples
```

| timestep   | temporal resolution     |
| stencil    | neighboring points used |
| resolution | detail level            |

# 2. Finite Difference (FD)

### Frequency

★★★★★

### Definition

Approximate derivatives using nearby points.

Derivative:

[
f'(x)
]

Approximation:

[
\frac{f(x+h)-f(x)}{h}
]

Visual:

```text id="4hpfgt"
●──●──●
```

Estimate slope.

Used for:

* PDEs
* heat
* wave equations

Pros:

* simple

Cons:

* can introduce artifacts

Your Jacobian approximations are FD-like.

# 4. Spectral Methods ★

### Frequency

★★★★★

Your project lives here.

Frequency:

[
u(x)

Visual:

waves

Pros:

# 5. Time Integration

Solve:

[
\frac{du}{dt}=F(u)
]

---

## Euler

### Frequency

★★★★★

### Definition

Small forward step.

[
u_{n+1}
=======

u_n+\Delta tF(u_n)
]

Pros:

* simple

Cons:

* unstable

---

## RK2 (YOUR CURRENT METHOD)

### Frequency

★★★★★

Two-stage estimate.

Stage 1:

[
k_1=F(u)
]

Stage 2:

[
k_2=F(u+\Delta tk_1)
]

Update:

[
u_{n+1}
=======

u_n+\frac12(k_1+k_2)
]

Pros:

* better accuracy
* moderate cost

---

## RK4

### Frequency

★★★★★

Four evaluations.

Error:

[
O(\Delta t^4)
]

More accurate.

More expensive.

---

## Implicit Methods

### Frequency

★★★★☆

Solve future state simultaneously.

[
u_{n+1}
=======

u_n+\Delta tF(u_{n+1})
]

Pros:

* stable

Cons:

* harder

Used for:

* stiff systems

# 7. CFL Condition ★

### Frequency

★★★★★

One of the most important concepts.

Equation:

[
CFL
===

\frac{u\Delta t}{\Delta x}
]

Meaning:

Information cannot move too far in one timestep.

Visual:

```text id="04q0zm"
wave
↓

next cell
```

Interpretation:

| CFL  | Meaning  |
| ---- | -------- |
| <0.5 | safe     |
| ~1   | caution  |
| >1   | unstable |

You already computed this.
