# Literature Verification Notes

## Purpose

This file records a first-pass verified bibliography for the preprint manuscript. It is not yet a final reference list. References below were added only when source metadata could be checked from accessible publisher, repository, DOI, or scholarly metadata pages.

The notes distinguish background theory from sources that are more directly relevant to this project's diagnostics. None of these references should be used to claim that the current project validates a fully stationary enstrophy cascade. The current project claim remains limited to residual `k^-3`-like spectral validation in selected peak-masked windows.

## 1. 2D Turbulence Review / Enstrophy Cascade Theory

### Two-Dimensional Turbulence

- Title: Two-Dimensional Turbulence
- Authors: Guido Boffetta and Robert E. Ecke
- Year: 2012
- Category: 2D turbulence review / enstrophy cascade theory
- Verification source: Annual Reviews metadata, DOI `10.1146/annurev-fluid-120710-101240`
- Why it is relevant to this project: Provides a modern review of two-dimensional turbulence, including the dual-cascade picture, inverse energy transfer, direct enstrophy transfer, friction drag, energy flux, and enstrophy flux.
- What claim it can support: The `k^-3` reference belongs to established 2D turbulence/enstrophy-cascade phenomenology, and flux/stationarity caveats are part of the standard interpretive framework.
- What claim it cannot support: It cannot show that this project's runs are statistically stationary or that the residual spectra validate a full enstrophy cascade.
- Where it may belong in the manuscript: Introduction; theory/background; limitations.
- Source confidence: high

### Two-Dimensional Turbulence: A Physicist Approach

- Title: Two-dimensional turbulence: a physicist approach
- Authors: Patrick Tabeling
- Year: 2002
- Category: 2D turbulence review / enstrophy cascade theory
- Verification source: ScienceDirect metadata, Physics Reports 362, pages 1-62, DOI `10.1016/S0370-1573(01)00064-3`
- Why it is relevant to this project: Provides broad physical context for 2D turbulence, including inverse cascade, direct enstrophy cascade, coherent structures, and experimental/numerical perspectives.
- What claim it can support: The manuscript's vocabulary and caution around cascades, coherent structures, and spectral interpretation are standard concerns in 2D turbulence.
- What claim it cannot support: It cannot directly support any numerical metric from Run 004, Run 009, Run 011, Run 012, or Run 013.
- Where it may belong in the manuscript: Introduction; background discussion; literature context.
- Source confidence: high
